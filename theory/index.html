§1 Governing equation and weak form¶

ρc ∂T/∂t = ∇·(D ∇T) + Q in the domain, with D the 2×2 conductivity matrix.

Boundary conditions on the boundary Γ (n = outward normal, q_n = −n·D∇T = heat leaving):

  • Fixed temperature: T = T̄
  • Heat flux into the body: −q_n = q̄
  • Convection: q_n = h (T − T∞)
  • Radiation to ambient: q_n = ε σ (T⁴ − T∞⁴)

Discretised with T ≈ N(ξ,η)·T_e the semi-discrete system is

C Ṫ + K T = F

All integrals carry the geometry factor g:

  • planar: g = thickness of the region [m] (default 1)
  • axisymmetric: g = 2π r, with r = the x coordinate at the integration point

so that every assembled force term is in watts.

§2 Element matrices¶

For each element, with B = the 2×n matrix of ∂N/∂x, ∂N/∂y and |J| the Jacobian determinant:

  • Conduction: K_e = Σ_gp Bᵀ D B · g · |J| · w
  • Capacitance: C_e = Σ_gp ρc · NᵀN · g · |J| · w
  • Heat generation: F_e = Σ_gp Q · Nᵀ · g · |J| · w

Orthotropic D with principal conductivities k1, k2 and material angle θ (radians, counter-clockwise from x): D = R diag(k1, k2) Rᵀ, R = [[cosθ, −sinθ],[sinθ, cosθ]]. Isotropic: D = k I.

Temperature-dependent properties are evaluated at each integration point from the interpolated temperature N·T_e.

Boundary (edge) element terms¶

For an edge with shape functions N (1D), |J_s| = ds/dξ:

  • Flux: F_e = Σ_gp q̄ · Nᵀ · g · |J_s| · w
  • Convection: K_e = Σ_gp h · NᵀN · g · |J_s| · w ; F_e = Σ_gp h T∞ · Nᵀ · g · |J_s| · w
  • Total heat flow P [W] applied to a boundary set: convert to uniform flux q̄ = P / A, where A = Σ over the set of ∫ g ds.
  • Total power P [W] applied to a region: Q = P / V, V = ∫ g dA.

§3 Shape functions and quadrature¶

Node ordering is gmsh ordering: corners counter-clockwise, then mid-side nodes in the order (0-1, 1-2, 2-0) for triangles and (0-1, 1-2, 2-3, 3-0) for quads.

T3 (ξ,η ∈ unit triangle): N = [1−ξ−η, ξ, η]

T6 with L1 = 1−ξ−η, L2 = ξ, L3 = η: N = [L1(2L1−1), L2(2L2−1), L3(2L3−1), 4L1L2, 4L2L3, 4L3L1]

Q4 (ξ,η ∈ [−1,1]), corner signs (ξi,ηi) = (−1,−1),(1,−1),(1,1),(−1,1): N_i = ¼(1+ξξi)(1+ηηi)

Q8 (serendipity): corners N_i = ¼(1+ξξi)(1+ηηi)(ξξi+ηηi−1); mid-sides with ξi = 0: N_i = ½(1−ξ²)(1+ηηi); with ηi = 0: N_i = ½(1+ξξi)(1−η²). Mid-side positions: (0,−1),(1,0),(0,1),(−1,0).

L2 edge (ξ ∈ [−1,1]): N = [½(1−ξ), ½(1+ξ)]

L3 edge, gmsh order (end, end, middle): N = [½ξ(ξ−1), ½ξ(ξ+1), 1−ξ²]

Quadrature (weights sum to the reference area: ½ for triangles, 4 for quads, 2 for lines):

Lumped capacitance (option)¶

  • T3, Q4: row-sum, C_ii = Σ_j C_ij.
  • T6, Q8: HRZ lumping, C_ii = C_ii(consistent) · (Σ_ij C_ij) / (Σ_k C_kk). Never use row-sum for quadratic elements (gives zero or negative corner terms).

§4 Fixed temperatures¶

Partition DOFs into free (f) and prescribed (p). Solve K_ff T_f = F_f − K_fp T̄_p. Never use the penalty method. Reaction heat flow at prescribed nodes (positive = heat entering the body through the constraint) for the transient system:

R_p = (C Ṫ + K T − F)_p

§5 Nonlinear steady solution¶

Residual at free DOFs: r(T) = F(T) − K(T) T (K includes convection and radiation tangent-free parts; F includes all load vectors). Radiation to ambient contributes to r

r_rad = −Σ_gp ε σ ((N·T)⁴ − T∞⁴) Nᵀ g |J_s| w

and to the tangent

K_rad = Σ_gp 4 ε σ (N·T)³ NᵀN g |J_s| w

Iteration (modified Newton — property derivatives dk/dT, dh/dT are deliberately omitted from the tangent):

  1. Assemble K(Tⁱ), F(Tⁱ), K_rad(Tⁱ), r(Tⁱ) with properties and coefficients at Tⁱ.
  2. Solve (K + K_rad)_ff ΔT_f = r_f.
  3. Line search: s = 1; while ‖r(Tⁱ + sΔT)‖ > (1 − 1e-4·s)‖r(Tⁱ)‖ and s > 1/32: s ← s/2.
  4. Tⁱ⁺¹ = Tⁱ + sΔT.
  5. Converged when ‖r_f‖₂ ≤ rtol · F_ref and ‖sΔT‖∞ ≤ ttol. F_ref = max(‖F‖₂, ‖K T‖₂, 1e-12). Defaults rtol = 1e-6, ttol = 1e-4 K, max 30 iterations.
  6. Not converged after the limit → raise ConvergenceError (steady) or cut the step (transient).

A problem is linear when no property, coefficient or load depends on T and there is no radiation. Detect this once; a linear problem takes exactly one solve with no iteration.

If any temperature becomes ≤ 0 K during iteration, treat the iteration as failed (halve the line-search step; if that fails, raise).

§6 Transient solution (θ-method)¶

With g(T, t) = F(T, t) − K(T) T − (radiation term) the "heat-flow imbalance", the step from t_n to t_{n+1} = t_n + Δt solves for T_{n+1}:

R(T_{n+1}) = C(T_θ) (T_{n+1} − T_n)/Δt − θ g(T_{n+1}, t_{n+1}) − (1−θ) g(T_n, t_n) = 0

with T_θ = θ T_{n+1} + (1−θ) T_n used only to evaluate ρc. Tangent: A = C/Δt + θ (K + K_rad) evaluated at the current iterate. Newton update: A_ff ΔT_f = −R_f. Line search and convergence test as in §5, with F_ref = max(‖C(T_{n+1}−T_n)/Δt‖₂, ‖F‖₂, ‖K T‖₂, 1e-12).

  • θ = 1 backward Euler (default; unconditionally stable, no oscillation)
  • θ = 2/3 Galerkin
  • θ = 1/2 Crank–Nicolson (second order; may oscillate after a thermal shock)

g(T_n, t_n) is stored from the end of the previous step, not recomputed. At a step where a prescribed temperature or a load jumps discontinuously, use θ = 1 for that one step.

Prescribed temperatures: set T_{n+1,p} = T̄(t_{n+1}) before the first iteration.

Linear case: A is constant while Δt is constant — factorise once and reuse (splu object cached, keyed on Δt).

§6.1 Automatic time stepping¶

After a converged step compute the predictor T_pred = T_n + (Δt/Δt_prev)(T_n − T_{n−1}) (for the first step skip the error test) and the error

e = ‖T_{n+1} − T_pred‖∞ / max(T_range, 1 K), T_range = max(T) − min(T) over the model

  • If e > 4·tol: reject the step, Δt ← Δt/2, redo.
  • Otherwise accept and set Δt_next = Δt · clip(0.9 √(tol/e), 0.5, 2.0).
  • Default tol = 0.02. Clamp to [Δt_min, Δt_max].
  • Newton failure: Δt ← Δt/4, redo. If Δt < Δt_min: raise ConvergenceError.
  • Always shorten a step so that it lands exactly on the next mandatory time: every requested output time, every breakpoint of every load table, and the end time.
  • Also limit the step so the largest nodal change ≤ max_dT_per_step if the user set it.

Suggested initial step (shown in the GUI): Δt₀ = h_min² / (4 α_max), α = k/(ρc), h_min = smallest element edge length.

Oscillation warning: if consistent capacitance is used and Δt < h² ρc /(6k) for more than 5% of elements, log a warning recommending lumped capacitance or a finer mesh.

§7 Recovered quantities¶

  • Gradient at any element point: ∇T = B T_e. Flux q = −D ∇T.
  • Nodal flux: evaluate q at each element's own nodes (B at the node's local coordinates), then average the contributions of all elements sharing the node that belong to the same region. A node on a material interface therefore has one flux value per region.
  • Element flux: value at the element centroid.
  • Heat flow through a boundary set [W] (positive out of the body):
    • convection set: Σ_gp h (T − T∞) g |J_s| w
    • radiation set: Σ_gp εσ(T⁴ − T∞⁴) g |J_s| w
    • flux set: −Σ_gp q̄ g |J_s| w
    • fixed-temperature set: −Σ R_p over its nodes (§4)
  • Stored energy rate: Ė = Σ (C Ṫ), with Ṫ = (T_{n+1} − T_n)/Δt.
  • Energy balance: (generation + heat in through all boundaries) − Ė = imbalance. Report imbalance / max(|terms|).

Characteristic lengths in a 2D model.

  • Horizontal plates. [I] defines L = A_s/P (Eq. 9.29). In a planar model a horizontal face is a strip of unit depth, so A_s/P is half the strip's width; [I] Example 9.3 uses w/2 in the same way.   • The jets take their L_c from these inputs, so a given L_c is refused.

§8.2 Correlations of [I] that are not used¶

Recorded so that no task adds them without a decision. On 2026-11-23 the owner judged the correlations in use adequate and declined the enclosure, mixed-convection and Table 8.1 f·Re additions (Q30.4):

  • Circular cylinder, Hilpert ([I] 7.52, Table 7.2) and Zukauskas (7.53). These cover the same case as Churchill–Bernstein (7.54), which is kept. Horizontal cylinder, Morgan (9.33, Table 9.1) is not used either; Churchill–Chu (9.34) is kept.
  • Liquid-metal forms: the flat plate (7.32) and fully developed tube flow (8.64, 8.65). Mercury is the only liquid metal built in. Other correlations used outside their Pr range warn as usual.
  • Flat plate with uniform surface flux (7.45–7.48) or an unheated starting length (7.60–7.64). The surface conditions these assume are not known to a load.
  • Tube banks (7.58, 7.59), packed beds (7.81), falling drops (7.57), and arrays of jets (7.73, 7.77). These need array geometry and a mean fluid temperature that a single-surface load does not have.
  • Laminar entry lengths (8.57, 8.58). These give a Nusselt number averaged from the inlet to x, but the stream needs a local value in each cell.
  • Colebrook friction (8.20) and laminar f·Re of non-circular sections (Table 8.1). Churchill 1977 is kept; it applies to circular ducts and to D_h. Using Table 8.1's f·Re would need a rule for joining it to the turbulent branch, which [I] does not give (OPEN_QUESTIONS Q30).
  • Isoflux vertical channels (9.46), inclined channels (9.47), and the isolated-plate optimum spacings (Table 9.3). The isothermal form 9.45 is used.
  • Enclosures: rectangular cavities, concentric cylinders and spheres (9.49–9.63). They couple two surfaces across a cavity, and a convection load sees only one ambient temperature (Q30).
  • Mixed free and forced convection (9.64). This needs two correlations in one load (Q30).
  • Boiling and condensation (chapter 10). The fluids here do not change phase.

§9 Flow solver¶

§9.1 Stream (fluid temperature along a wall)¶

A stream is a 1D fluid path with mass flow ṁ [kg/s], inlet temperature T_in, flow area A, wetted perimeter P_wet (for D_h), fluid, and one or more wall boundary sets that it cools or heats. The stream is divided into N cells along its path coordinate s. Fluid node 0 is the inlet (prescribed T_in); fluid node j is the outlet of cell j−1. Fluid nodes are extra DOFs appended after the mesh nodes.

Each wall edge element i belongs to the cell containing the s-coordinate of its midpoint (s = projection of the midpoint onto the stream path polyline). Per edge element:

  • conductance G_i = h_i · ∫ g ds over the edge (h from §8.1 using the cell's upstream fluid-node temperature for properties, lagged)
  • wall temperature T_w,i = Σ_j w_j T_j with w_j = ∫ N_j g ds / ∫ g ds

Per cell with upstream fluid node u and downstream node d:

  • G = Σ G_i, T̄_w = Σ G_i T_w,i / G, NTU = G /(ṁ c_p)
  • φ = (1 − e^(−NTU)) / NTU (φ = 1 when NTU < 1e-8)
  • Effective fluid temperature seen by the wall: T_f* = (1 − φ) T̄_w + φ T_u
  • Heat from wall edge i to fluid: Q_i = G_i (T_w,i − T_f*)
  • Fluid energy equation: ṁ c_p (T_d − T_u) − Σ_i Q_i = 0

Q_i is removed from the wall nodes of edge i with the same weights w_j. This scheme is exact for a constant wall temperature per cell, cannot oscillate for any NTU, and conserves energy exactly. The resulting matrix rows are linear in the unknown temperatures (for frozen h and c_p) and unsymmetric. Fluid thermal storage is neglected (quasi-steady fluid) — state this in the user guide.

Matrix contributions for one cell, written as a conductance-type matrix K_s such that the heat leaving each DOF is K_s·T: for wall DOF a (weight w_a,i on edge i): row a gets Σ_i w_a,i G_i (T_w,i − (1−φ) T̄_w − φ T_u), and row d gets ṁ c_p (T_d − T_u) − Σ_i G_i (T_w,i − (1−φ) T̄_w − φ T_u). Expand T_w,i and T̄_w into nodal weights to obtain the coefficients. Implement this by building the small dense cell matrix with NumPy and scattering it.

A stream may also be through-plane (planar models: flow perpendicular to the model plane, such as a cooling hole seen in cross-section). Then the fluid temperature is uniform on the boundary set and equals the specified bulk temperature; the stream only supplies h from §8.1. No fluid DOFs are created.

§9.2 Network (flow distribution)¶

Nodes carry pressure; branches are ducts (§8.1 pressure drop), minor-loss elements, or fixed-flow sources. Boundary conditions: prescribed pressure at a node, or prescribed mass flow into a node. Unknowns: nodal pressures.

Branch law: ṁ = sign(Δp) · A √( 2 ρ |Δp| / (f L/D_h + K_minor) ). Linearise as ṁ = c (p_i − p_j) with c = ṁ/Δp from the previous iterate (start with laminar f = 64/Re assumption at Re = 1000). Iterate: assemble Σ c (p_i − p_j) = source at each node, solve, update ṁ and f, under-relax c with factor 0.5, until the largest relative change in any ṁ < 1e-6 (max 200 iterations). Each branch's ṁ then feeds the stream attached to it. Fluid properties in the network use each branch's mean stream temperature; the hydraulic and thermal solutions are alternated inside the nonlinear loop (hydraulics updated at most once per nonlinear iteration, and only when a branch's mean temperature has changed by more than 1 K).

§10 Enclosure radiation (grey, diffuse)¶

Not available in this version

Enclosure radiation (surface-to-surface radiation, §10 to §10.2) is not implemented in this version (milestone M9 is on hold). The theory is kept here for completeness; no solver module uses it yet.

Faces = boundary edge elements of the enclosure, i = 1…n, length-based area A_i = ∫ g ds, emissivity ε_i, face temperature T_i = Σ w_j T_j (weights as in §9.1), E_b,i = σ T_i⁴. View-factor matrix F (n×n). Open enclosures: F_i∞ = 1 − Σ_j F_ij radiates to a black ambient at T_∞.

With E = diag(ε): solve (I − (I − E) F) J = E·E_b + (I − E) F_∞ σT_∞⁴ for radiosity J. Net flux leaving face i: q_i = J_i − Σ_j F_ij J_j − F_i∞ σ T_∞⁴.

Precompute once per mesh: M = (I − F)(I − (I−E)F)⁻¹ E and the ambient vector. Then q = M E_b + q_∞, heat Q_i = A_i q_i, distributed to the face's nodes with weights w_j. Residual contribution: −Q. Tangent: ∂Q_i/∂T_j = A_i M_ij 4σT_j³ (dense block; insert it fully when n ≤ 3000, otherwise only its diagonal).

§10.1 View factors, planar¶

For two straight segments i (endpoints a1,a2) and j (endpoints b1,b2) that fully see each other (Hottel crossed strings):

F_ij = [ |a1b2| + |a2b1| − |a1b1| − |a2b2| ] / (2 L_i) (use the absolute value; "crossed" strings are the two that intersect)

Visibility: a pair is facing if each midpoint lies on the outward-normal side of the other. A pair is fully visible if facing and none of the four end-to-end sight lines intersects any other enclosure segment. If facing but not fully visible, subdivide both segments into m = 8 sub-segments, apply crossed strings to each fully visible sub-pair (testing sight lines between sub-segment endpoints), and sum: F_ij = Σ_sub L_sub,i F_sub / L_i. Use a uniform grid or shapely.STRtree-free hand-written segment-intersection test vectorised with NumPy.

Afterwards enforce reciprocity (A_i F_ij ← ½(A_i F_ij + A_j F_ji)) and, for closed enclosures, scale rows so Σ_j F_ij = 1 (repeat both steps 5 times).

§10.2 View factors, axisymmetric (task M9.5)¶

Each face is a conical ring. Compute F_ij by numerical integration of the 3D kernel cosθ_i cosθ_j /(π r²) over the azimuth of ring j (and sub-divisions of both generators), with blockage tested by intersecting each ray with every other ring's cone frustum. Validate against concentric-cylinder and coaxial-disk closed forms (V-22).

§11 Thermal contact resistance¶

Along an interface curve the mesh has duplicated nodes (one set per side). For each pair of matching edge elements with contact conductance h_c [W/m²·K] add, over the 2n interface DOFs [side A; side B]:

K_c = Σ_gp h_c g |J_s| w · [[NᵀN, −NᵀN], [−NᵀN, NᵀN]]

§12 Phase change (apparent heat capacity)¶

Not available in this version

Phase change (apparent heat capacity) is not implemented in this version (task M10.2 is on hold). The theory is kept here for completeness; no solver module uses it yet.

Latent heat L released between T_sol and T_liq is modelled by replacing ρc with ρc + ρL/(T_liq − T_sol) for T_sol ≤ T ≤ T_liq. Require T_liq − T_sol ≥ 1 K, force lumped capacitance and backward Euler, and limit max_dT_per_step to (T_liq − T_sol)/2.
