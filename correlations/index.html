Common relations (Theory §8)¶

h = Nu · k_f / L_c. Fluid properties at the film temperature T_film = (T_s + T∞)/2 unless the correlation states otherwise. T_s is the wall temperature of the previous nonlinear iteration (lagged), either local (at each integration point; default) or the area average over the boundary set (option).

Re = ρ V L/μ, Pr = μ c_p/k_f, Ra = g β |T_s − T∞| L³ Pr ρ²/μ², g = 9.80665 m/s². For ideal gases β = 1/T_film; for liquids β comes from the property table.

duct_internal: Internal flow, circular or by hydraulic diameter¶

Formula (copied from the theory document):

Re = ṁ D_h /(A μ), D_h = 4A/P_wet. Properties at the bulk fluid temperature.
Laminar (Re ≤ 2300): Nu_lam from the table (constant wall T: circular 3.66, parallel plates both heated 7.54, parallel plates one side insulated 4.86, square 2.98; constant flux: 4.36, 8.23, 5.39, 3.61).
Turbulent (Re ≥ 4000): Gnielinski Nu = (f/8)(Re − 1000) Pr / [1 + 12.7 (f/8)^½ (Pr^⅔ − 1)], f = (0.790 ln Re − 1.64)⁻².
Transition (2300 < Re < 4000): linear interpolation in Re between Nu_lam and Nu_Gnielinski(Re = 4000).
Optional: Dittus–Boelter, Nu = 0.023 Re^0.8 Pr^n, n = 0.4 if wall hotter than fluid, else 0.3.
  • Characteristic length L_c: D_h

  • Validity range (as recorded): Gnielinski: 0.5 ≤ Pr ≤ 2000, Re ≤ 5e6. Dittus–Boelter: Re ≥ 1e4. (The validity column of the §8 table is empty for this entry; the ranges are those stated in §8.1.)

Validity ranges and warnings¶

For the horizontal-plate pair, pick "up" or "down" automatically at run time from the sign of (T_s − T∞) and the declared face direction. Outside a validity range: still evaluate, and emit one warning per boundary condition per solve. plate_forced_local needs the leading-edge point and flow direction; x is the distance of the integration point from the leading edge along the flow direction (minimum x = 1e-6 m).

Internal duct flow, friction factor and pressure drop (Theory §8.1)¶

This is the text of §8.1 of the theory document, unchanged. It holds the laminar Nusselt numbers, the turbulent and transition relations, the optional Dittus–Boelter relation, the Churchill friction factor and the pressure drop of a duct.

Re = ṁ D_h /(A μ), D_h = 4A/P_wet. Properties at the bulk fluid temperature.

  • Laminar (Re ≤ 2300): Nu_lam from the table below.
  • Turbulent (Re ≥ 4000): Gnielinski Nu = (f/8)(Re − 1000) Pr / [1 + 12.7 (f/8)^½ (Pr^⅔ − 1)], f = (0.790 ln Re − 1.64)⁻² (valid 0.5 ≤ Pr ≤ 2000, Re ≤ 5e6).
  • Transition (2300 < Re < 4000): linear interpolation in Re between Nu_lam and Nu_Gnielinski(Re = 4000).
Cross-section Nu_lam, constant wall T Nu_lam, constant flux
Circular 3.66 4.36
Parallel plates, both heated 7.54 8.23
Parallel plates, one side insulated 4.86 5.39
Square 2.98 3.61

Default is the constant-wall-temperature value. Optional user selection: Dittus–Boelter, Nu = 0.023 Re^0.8 Pr^n, n = 0.4 if wall hotter than fluid, else 0.3 (Re ≥ 1e4).

Friction factor, all regimes (Churchill 1977), roughness e: f = 8 [ (8/Re)¹² + (A + B)^(−1.5) ]^(1/12), A = [2.457 ln( 1 / ((7/Re)^0.9 + 0.27 e/D_h) )]¹⁶, B = (37530/Re)¹⁶

Pressure drop of a duct of length L with minor-loss coefficient K_minor: Δp = (f L/D_h + K_minor) · ρ V²/2, V = ṁ/(ρ A).

The stream and network equations that use these relations are in Theory §9.
