Verification cases¶

Generated page

This page is generated from docs/verification.md by scripts/build_guide.py. Do not edit it here: change the source and run the script again.

Which cases are active¶

The program is checked against the cases below: each has an analytic or published answer and a tolerance. The tolerances are part of the specification and are never loosened to make a case pass. The computed results are not part of this page.

These cases are specified but not active in this version, because the feature they check is on hold:

  • V-22a to V-22d: enclosure radiation (milestone M9, on hold)
  • V-23: enclosure radiation (milestone M9, on hold)
  • V-24: enclosure radiation (milestone M9, on hold)
  • V-36: phase change (task M10.2, on hold)

All other cases are active in this version. The cases V-33 and V-37 have no runnable script in examples/; they are built inside their tests. V-25 and V-26 are checks of functions, not of a model.

The cases¶

Each case becomes one test in tests/verification/test_vNN_*.py and one runnable script in examples/. Tests compute the analytic answer from the formula given here — do not paste in pre-computed numbers, except the published NAFEMS targets.

Unless stated: planar, thickness 1 m, k = 50 W/m·K, ρ = 7800, c = 500, temperatures in K. "1D" cases are modelled as a 2D strip (length L in x, height L/10) with the long sides adiabatic. Run every case with all four element types unless noted. Tolerance is on the relative error against the analytic value, with the mesh size given.

Extensibility guard¶

ID Problem Requirement
V-37 3D patch test. Inside the test only: register a 4-node tetrahedron Tet4 (N = [1−ξ−η−ζ, ξ, η, ζ], 1-point rule at (¼,¼,¼) with w = 1/6, facet type T3) and build a Mesh with dim = 3 of a unit cube split into 6 tetrahedra plus one interior node arrangement of your choice. Impose T = 300 + 10x + 20y + 30z on all boundary nodes, k = 50, and solve with the unmodified kernel, ConductionTerm and steady driver.
