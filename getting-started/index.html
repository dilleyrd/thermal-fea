Getting started¶

This page describes the workflow as the program presents it, first in the window and then from the command line and from Python. The tutorials apply it to worked problems.

The program has not yet been reviewed on a real screen by its owner (see Limitations). Layout and wording of the window may change.

The window¶

Start the program as described in Installation.

  • Model dock (top left): the model tree.
  • Properties dock (below it): the panel of the item selected in the tree.
  • Viewport (centre): the geometry, the mesh, load symbols and result plots.
  • Messages dock (bottom): the solver log. An Issues dock is tabbed with it and lists the findings of validation. The View menu shows and hides the docks, and switches the load symbols on and off ("Load symbols").
  • Toolbar: the selection modes None, Point, Curve, Surface, Node and Element, and "Fit view" (the key F).

Menus: File, Edit, View, Geometry, Mesh, Solve, Results, Tools, Help.

Selecting in the viewport¶

A click selects the item under the pointer (8 pixels of tolerance). Ctrl-click adds to or removes from the selection. A click on nothing clears it. A drag longer than 4 pixels selects by a box: curves must lie wholly inside the box, surfaces are chosen by their bounding box, elements by their centre. Changing the selection mode clears the selection. The mouse wheel zooms and the middle button pans.

The workflow¶

The model tree lists the parts of a model in the order you normally fill them in:

Tree node What it holds
Geometry the geometry operations, in the order they were applied
Materials the materials used by the model
Regions which material (and thickness and material angle) each surface selection has
Mesh mesh settings and the Generate mesh button
Initial Condition the starting temperature of a transient analysis
Loads & Boundary Conditions fixed temperatures, fluxes, convection, radiation, symmetry, ...
Contacts thermal contact between regions
Flow streams and networks
Enclosures enclosure radiation (not available in this version)
Analysis Settings steady or transient, time stepping, output, nonlinear controls
Solution the result objects (contour plots, vector plots) after a solve

Right-click a node to see its actions. Loads can be added, renamed, duplicated, suppressed and deleted. Materials, streams, contacts and enclosures can be renamed, duplicated and deleted.

1. Geometry¶

The Geometry menu has Point..., Line..., Arc..., Spline..., Rectangle..., Circle..., Polygon..., Surface from curves..., Union..., Cut..., Intersect..., Translate..., Rotate..., Mirror..., Scale..., Delete..., Import STEP/BREP/DXF..., Snap to grid and Rebuild geometry.

Each operation opens a dialog with numeric entry. The geometry is rebuilt by itself after every OK. Notes:

  • For Union, Cut and Intersect select the shapes in the viewport first. The earliest selected shape (in history order) is the object; the others are the tools.
  • The parameters of Translate, Rotate, Mirror and Scale are always in SI (lengths in metres, angles in radians), whatever the display units.
  • An operation that later operations refer to cannot be deleted.
  • If a rebuild fails, the old geometry stays, is marked out of date, and the error is reported. Edit > Undo recovers.
  • DXF import needs the dxf extra (Installation). See Limitations for what it ignores.
  • A new model is a planar model. The window has no control to change that.

2. Materials and regions¶

Right-click Materials and choose Add material. The new material starts as a copy of the first library material, so check every value. Each physical property has a mode box (Constant, Table or Expression) above its value; leave it on Constant for a constant. Tools > Material library... opens the built-in library (Materials).

Right-click Regions and choose Add region. In its Selection field press "Pick in viewport", set the toolbar to Surface, click the surfaces, press Apply, then press "Pick in viewport" again to switch picking off. Choose the Material, and set the Thickness (planar models) and the Material angle if needed.

3. Loads and boundary conditions¶

Right-click Loads & Boundary Conditions, choose Add, then one of:

Add Fixed Temperature, Add Heat Flux, Add Heat Flow, Add Heat Generation, Add Heat Power, Add Convection, Add Correlation Convection, Add Radiation to Ambient, Add Symmetry, Add Adiabatic.

Each load has a Selection field that works as described for regions (set the toolbar to Curve for edges). Selecting a load in the tree highlights its curves, and the viewport shows load symbols.

  • Press Enter after typing a number. The value is applied when you press Enter or leave the field. Each applied change is one undo step.
  • A value may be a Constant, a Table against time, or an Expression of time, position and temperature. Expressions are always evaluated in SI units (Units).
  • Heat flows count as positive when they enter the body.
  • Correlation Convection takes its heat-transfer coefficient from a correlation. A correlation used outside its validity range still gives a value and logs one warning.
  • A Contact (right-click Contacts, Add contact) starts with an empty selection and a conductance of 0, which you must set. A temperature-dependent conductance is refused.
  • Streams and networks are under Flow (right-click, Add stream). Results > Flow results... shows the fluid temperature along the stream.
  • Tools > HTC calculator... evaluates a correlation at single values without a model.

4. Mesh¶

Click the Mesh node. The panel has, among others, "Global element size", "Element order" and "Element shape". Press Generate mesh (or use Mesh > Generate mesh). The status bar reports the number of nodes and elements and the mesh is drawn in the viewport.

5. Analysis settings and initial condition¶

Click Analysis Settings. "Analysis type" is steady or transient. A transient analysis shows "End time", "Initial time step", "Smallest time step", "Largest time step", "Adaptive time step", "Time-step tolerance", "Largest temperature change per step", "Theta", "Lumped capacitance" and the output controls ("Output steps", "Store every n-th step", "Output times"). The nonlinear controls are "Residual tolerance", "Temperature tolerance", "Maximum iterations" and "Line search".

Click Initial Condition for a transient analysis. "Kind" is uniform, expression, per_region or from_results. The initial state (step 0) is always stored.

6. Validate and solve¶

  • Solve > Validate checks the model before solving and lists errors and warnings in the Issues dock. Errors must be fixed first.
  • Solve > Solve runs the analysis on its own thread. A window titled "Solving" shows the progress and stays open, with a "Finished" state, so you can read the residual chart.
  • Solve > Cancel solve stops a run. The steps already written are kept.
  • Solve > Continue transient run continues a transient run (see below).

The Messages dock shows the log, including the heat entering through each load and the relative imbalance of the energy balance.

7. Results¶

After a solve the Solution node holds a temperature contour (for example "Temperature 1"). Its panel has "Levels", "Banded (otherwise smooth)", "Colour scale" and "Mesh overlay", and, for a transient run, a "Step" slider and spin box, a "Time" box and "Play".

The Results menu has: Add contour, Add vector plot, Probe, Play animation, Nodal history..., Path plot..., Finish path plot, Cancel path plot, Heat-flow history, Energy balance and Flow results.... Nodal history and Path plot ask you to pick nodes or path points in the viewport first. Probe shows x, y and the value at the pixel you click. It is a rough check; use the CSV export for exact values.

File > Export has: Viewport image..., Nodal results (CSV)..., ParaView (VTU)... and Animation (GIF).... The CSV has the columns step, time, node, x, y, T, qx, qy in SI units. Charts have their own export.

Which things are out of date¶

An edit makes parts of the work out of date. What is affected depends on what you changed:

You changed Out of date
the geometry geometry, mesh and results
the mesh settings, the model type, or a selection the mesh settings use mesh and results
anything else (loads, materials, analysis settings, ...) results only

How it shows:

  • Results panels show "These results are out of date: the model changed since the solve."
  • Chart windows are marked "(out of date)" in their title when new results arrive. They are not redrawn.
  • Solve is not available while the geometry or the mesh is out of date. Press Rebuild geometry and Generate mesh first (the status bar says "The mesh is out of date; regenerate it before solving").

Changing the display units (Units) makes nothing out of date.

Selection tags and the selection named "all" are caches of the build. A rebuild is not an undo step and does not make anything out of date by itself.

If you edit the model while a solve is running, the solve uses its own copy. When it finishes, the results are stored but marked out of date. If the mesh or the build was replaced meanwhile, the results are discarded (the file stays on disk).

Undo and redo¶

Edit > Undo and Edit > Redo (Ctrl+Z, Ctrl+Y). Every applied property change, every geometry operation, every change of units and every tree action (add, rename, duplicate, delete) is one undo step.

Units¶

Tools > Units... chooses the units numbers are shown and typed in. The default is SI with temperatures in kelvin. See Units. Press Enter after typing, and remember that 100 degC is 373.15 K when the units are K.

Examples¶

File > Examples opens ready-made models: the verification cases V-01 to V-21, V-27 to V-29, V-32 and V-35 (Verification). They are good starting points: open one, look at how it is set up, change it.

Files and where results are stored¶

  • File > New, Open..., Save, Save As... and Recent files work as usual. The model is a JSON file (.tfea).
  • Results are stored in an HDF5 file named after the model with .h5 added: model.tfea.h5 beside model.tfea. A model that was never saved writes its results to a temporary folder.
  • When you open a saved model, its results file is attached again once a mesh exists, so press Generate mesh after opening to see the results.
  • The results file also holds a copy of the model it was solved from.

Continuing a transient run¶

A transient run can be continued from its last stored step to a later end time. The new steps are added to the same results file.

  1. Raise "End time" in Analysis Settings. (A run that was cancelled can be continued without raising it.)
  2. Choose Solve > Continue transient run.

On the command line: thermalfea solve model.tfea --restart. From Python: api.solve(model, mesh, path=..., restart=True).

What to know:

  • The mesh, the materials, thicknesses and material angles of the regions, and the streams must be the same as in the results file, or the restart is refused and the file is left unchanged. So is a steady solution, a last step that did not converge, and an end time the file has already reached.
  • Loads and solver settings may change. The continued steps use the current model, which replaces the model stored in the results file. A load that you changed takes effect from the restart time.
  • With a fixed time step the continued run repeats an uninterrupted run (to round-off in the linear case). With adaptive stepping the controller's history is not stored, so the steps differ from those of an uninterrupted run within the time-stepping tolerance.

From the command line¶

Build and save the model in the window (File > Save) or from a script, then:

thermalfea info model.tfea
thermalfea solve model.tfea

info prints counts and a quality line. solve prints one progress line per step and a text summary, and writes model.tfea.h5 (Installation has the options and exit codes). Results can then be read by the Python API or opened in the window.

From Python¶

Everything the window does is available from thermalfea.api. This script builds a plate, solves it, prints the summary and saves the model:

from thermalfea import api
from thermalfea.model.bcs import Convection, FixedTemperature

model = api.new_model("planar", name="plate")
geo = api.Geometry(model)
geo.rectangle(0.0, 0.0, 0.2, 0.1)
built = api.build(model)
api.select_curves(model, built, name="bottom", where=lambda c: abs(c.center[1]) < 1e-9)
api.select_curves(model, built, name="top", where=lambda c: abs(c.center[1] - 0.1) < 1e-9)
api.assign_region(model, "all", material="Aluminium 6061-T6")
model.bcs.append(FixedTemperature("base", "bottom", T=373.15))
model.bcs.append(Convection("cooling", "top", h=25.0, T_inf=293.15))
model.mesh_settings.global_size = 0.01
mesh = api.mesh(model, built)
results = api.solve(model, mesh, built=built)
print(api.summary(results))
api.save(model, "plate.tfea")

All values are SI, with temperature in kelvin. Other calls: api.load, api.plot_contour, api.plot_vectors, api.plot_path, api.plot_history, api.export_csv, api.export_vtu, api.export_animation and api.htc. Without path=, api.solve writes the results to a temporary folder; api.results_path(model_path) gives the name beside a model file. Pass built= to api.solve so that the model is validated first.
